# A5 页面操作与交接

## 交付范围

A5 实现三个通过 HTTP API 访问的 Streamlit 页面：模型版本、监测指标、告警处置。入口为 `streamlit_app.py`，页面在 `ui/pages/`，共享客户端在 `ui/api_client.py`。界面不读取模型文件或数据库，不使用跨会话全局缓存保存令牌或查询结果。

补充 `GET /api/v1/me` 返回服务端解析的身份 ID、角色和模型授权，不返回令牌。每次界面重绘重新查询身份；所有操作仍由后端独立检查角色及模型范围。现阶段使用 A3 演示令牌，正式账号、JWT、审计查询和固定版本复现由 B 接入。

## 环境与启动

在项目根目录使用 Python 3.12.14 Windows AMD64。已有模型包要求其环境清单中的版本一致。完整依赖锁在 `requirements-a5.lock.txt`，包含 A3 的依赖及 Streamlit 1.66.1、pandas 3.1.1、Altair 6.3.0；绘图使用 Streamlit 内置折线图，不需要 Plotly。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-a5.lock.txt
```

正常运行需要三个终端。先按 [A3 操作说明](A3-接口操作与交接.md)设置两枚独立演示令牌及数据库环境变量，再启动 API：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```

第二个终端使用相同 `DATABASE_URL`、`ARTIFACT_ROOT` 启动 Worker：

```powershell
$env:DATABASE_URL = 'sqlite:///./data/runtime/platform.db'
$env:ARTIFACT_ROOT = './artifacts'
.\.venv\Scripts\python.exe -m app.worker
```

第三个终端启动页面，默认端口 8501：

```powershell
$env:API_BASE_URL = 'http://127.0.0.1:8000'
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

访问 `http://127.0.0.1:8501`，输入已配置的管理员或 scorer 演示令牌。配置只从环境变量读取，不自动加载 `.env`。后端地址由服务端环境变量指定；页面不允许输入任意地址后携带令牌访问。令牌保存在当前 Streamlit 服务端会话中，退出时清空，不写入 URL、导出、共享缓存或业务日志。

## 页面操作

模型版本：核对两版 UUID、状态、受信任摘要、激活状态；管理员勾选确认后激活。非管理员只有查看入口。操作保存后点击刷新核对。评分继续使用 A3 API，页面不接受任意模型包上传。

监测指标：选择模型版本和页码，按指标筛选本页数据，核对 UTC 窗口、单位、样本数、统计状态和修订号。表中比例是 0—1，空值不会替换为零。只有非过期且数值有效的点进入趋势图。`insufficient_samples` 表示样本不足，`stale` 表示存在未消费事件或修订待计算。管理员另可查看 Worker 心跳、积压和隔离任务。

规则表显示历史及未来规则，不能把第一条规则当作所有历史窗口的实际规则。管理角色可选择指标、特征、阈值、最少样本数及未来 UTC 整分钟生效时间，创建追加版本；PSI 最少 200 样本。窗口冻结的实际规则在告警证据中展示。

告警处置：按页和状态查看，选中告警核对阈值、实际数值、样本数、最少样本数、冻结规则版本与窗口 ID。展开完整证据及修订历史，查看窗口标识、冻结规则和操作历史。`condition_active` 与 `open/acknowledged/closed` 分别表示当前条件和人工处置流程。先认领，再填写说明关闭；管理员可关闭其他人的已认领告警，risk_manager 仅能关闭自己认领的告警。迟到修正消退不会删历史或自动重开已关闭告警。

每页 30 条，筛选和趋势明确限定为本页。API 目前未返回总数，因此提供页码和空页说明，没有虚构总页数。刷新由按钮触发，不在后台不断轮询。

## 失败与重试

HTTP 401 清空会话，403 提示授权不足，409 提示刷新核对状态，422 提示检查字段，503 或网络失败提示服务不可用。客户端不自动重发 POST，不展示服务器原始异常。相同路径和相同命令内容沿用同一幂等键，避免网络结果未知时重复创建；内容变化生成新键。重新登录清空该会话的命令键。收到成功提示后清除本次命令键，再刷新核对状态；后续主动操作会生成新键，因此切换到其他版本后仍能再次激活同一版本。

## 独立合成数据演示

```powershell
.\.venv\Scripts\python.exe -m scripts.preview_a5
```

此脚本每次在 `data/runtime` 下创建独立的带时间标识演示目录，默认使用本地端口 API 18005、UI 18505。可通过 `--directory`、`--api-port`、`--ui-port` 指定目录和端口。生成临时演示凭据和 40 条评分（其中 10 条收入缺失），通过 API 保存后消费，并显式将测试结算时钟推进 120 秒，得到缺失告警和 PSI 样本不足状态。随后启动连续 Worker 和页面。未修改源评分时间，不是实时延迟或吞吐测试。启动后会显示本次演示目录，凭据保存在该目录的 `credentials.json`，种子统计保存在 `seed-summary.json`。Ctrl+C 关闭脚本及其子进程。默认运行会生成新目录，显式指定的目录需为空。
