# 图形源文件说明

本目录包含两类图形源文件，用途不同。

## 1 `.mmd`（Mermaid 源文件）

设计文档引用的原始图形，在 GitHub 与支持 Mermaid 的编辑器中直接预览。`A5-*.mmd` 由成员 A 编写，内容对应 A5 的业务架构、逻辑架构与一级数据流图。

## 2 `B-*.svg`（报告打印版）

课程实验报告要打印成 A4。A5 中两张横向流程图在 A4 纵向页面上按 16cm 宽缩放后，文字实测只有约 3—4pt，无法阅读：

| 原图 | 原始尺寸 | 宽高比 | A4 纵向 16cm 宽时的字高 |
|---|---|---|---|
| A5-business | 1568×190 | 8.25 | 约 4pt |
| A5-dfd-level1 | 1568×106 | 14.8 | 约 4pt |

`B-*` 版本由 `build_print_figures.py` 生成，**只调整布局分组与画布比例，节点含义、编号（1.0—6.0、D1—D5）、数据流名称与方向均与 A5 源文件一致**。一级数据流图拆为两张，是因为 6 个处理与 22 条数据流在单张 A4 纵向页上无法同时保证完整与可读。

生成方式：

```bash
python build_print_figures.py
```

输出同目录下的三个 SVG。转 PNG 可用浏览器或任意矢量工具，当前 `docs/figures/` 中的 PNG 由 Edge 无头模式按 2 倍缩放导出。
