## 2 训练方案与隔离

固定六个数值特征：age、monthly_income、debt_income_ratio、past_due_count、loan_amount、employment_years。customer_ref 和 synthetic_default_label 不进入特征。

SimpleImputer 使用训练集的中位数；StandardScaler 在填补后的训练集上拟合；LogisticRegression 使用 lbfgs、max_iter=1000、tol=1e-8、固定种子 20261104，线程限制为 1。测试集与参考样本均不参与拟合。

v1 使用 C=1.0，v2 使用 C=0.5，两个版本均预设阈值 0.5。这里只演示预先确定的版本，不根据测试 AUC 进行参数或阈值调优。保留两个版本不是证明 v2 优于 v1。

## 3 实测评估

留出测试集共 1,000 条，正标签 259 条，负标签 741 条；全部属于合成数据。

- v1：ROC AUC 0.797800；准确率 0.786；精确率 0.655172；召回率 0.366795；F1 0.470297；Brier score 0.151637。
- v2：ROC AUC 0.797857；准确率 0.786；精确率 0.655172；召回率 0.366795；F1 0.470297；Brier score 0.151638。
- 两版混淆矩阵均为 TN=691、FP=50、FN=164、TP=95。只预测多数类的准确率为 0.741，因此不能只展示总体准确率而忽略漏判。

当前阈值下召回率约 36.7%，说明不少模拟正标签没有被判到阈值以上；本次保持预设阈值以满足数据隔离，不使用测试集反复调整。后续如研究阈值，应另分验证集，并为新配置创建新版本。

原始指标分别见 [v1 evaluation](../artifacts/credit-logreg-v1/evaluation.json) 和 [v2 evaluation](../artifacts/credit-logreg-v2/evaluation.json)。这些数值不代表真实金融业务效果。

## 5 安装与使用

当前项目 `.venv` 已安装 A2 依赖；后续在项目根目录直接运行：

```powershell
.\.venv\Scripts\python.exe -m scripts.verify_model --version credit-logreg-v1
.\.venv\Scripts\python.exe -m scripts.verify_model --version credit-logreg-v2
.\.venv\Scripts\python.exe -m scripts.score_model --version credit-logreg-v1 --input examples/A2-score-input.json
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

其他机器先用约定 Python 创建虚拟环境，再安装：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-a2.lock.txt
.\.venv\Scripts\python.exe -m pip check
```

`py -3.12` 只选择 3.12 系列，不保证精确为 3.12.14；加载已交付包前必须核对 environment.json。如果 Python 或系统不符，可保留当前两个包，在自己的环境生成新版本：

```powershell
.\.venv\Scripts\python.exe -m scripts.train_model --version credit-logreg-local-v1 --regularization-c 1.0
.\.venv\Scripts\python.exe -m scripts.verify_model --version credit-logreg-local-v1
```

训练命令默认目标 v1 已存在，再次运行会明确拒绝覆盖。新版本包的 joblib 文件默认被 Git 忽略；只有两个已检查的演示包被明确允许纳入版本控制。

## 6 给 B 和 A3 的调用约定

开发调用示意：

```python
from app.modules.models.bundle import load_registered
from app.modules.scoring.predict import score_one

bundle = load_registered("credit-logreg-v1")
result = score_one(bundle, {
    "customer_ref": "SYN-DEMO-1",
    "age": 35,
    "monthly_income": "8000.00",
    "debt_income_ratio": 0.4,
    "past_due_count": 1,
    "loan_amount": "100000.00",
    "employment_years": 10,
})
```

B 接入数据库后，推荐调用 `load_bundle(version, expected_manifest_sha256, root)`，其中 expected_manifest_sha256 来自已审核的版本记录。数据库的 model_version_id 是 UUID；这里的 model_version 是包目录版本名，两者需在版本表中显式映射。

A3 保存 result 中的原始输入、规范化输入、缺失字段、解释、阈值和版本；A3 自行补充请求编号、真实耗时、状态与事务留痕。A2 不伪造 prediction_id、受理时间或数据库持久化结果。

缺失字段允许为 None；CSV 空字符串可规范化为 None；金额必须是最多两位有效小数的十进制字符串。超范围、无穷值、布尔值充当数值或混入标签时明确报错。
